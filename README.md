# Travel Booking Website

## 1. Tên sản phẩm

Website đặt tour du lịch (Tour Booking)

## 2. Đối tượng

- Người muốn tìm kiếm và tham khảo các tour du lịch.
- Người muốn lựa chọn và đặt tour phù hợp với nhu cầu.

## 3. Giá trị mang lại

- Giúp người dùng dễ dàng tìm kiếm và lựa chọn tour.
- Cung cấp thông tin cần thiết về các tour du lịch.
- Giúp quá trình đặt tour thuận tiện và trực quan.
